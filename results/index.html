Results. Where docenta stands on public benchmarks, beside the numbers others have published.

SKY, LLC · docenta 0.3.2 · measured 2026-10-30 and 2026-10-31 on one MacBook Pro (M4 Max)

Where docenta stands, in four lines

  • LongMemEval-S retrieval: in the top band of the published retrievers measured the same way: 0.956 of questions find an evidence session in the top five, against 0.966 for the best raw retriever we found published (MemPalace, MiniLM embeddings) and 0.862 for a stemmed BM25. Grep over the same files finds 0.75.
  • LoCoMo retrieval: ahead of the paper's own retrieval baseline at five and ten sessions (80.0 and 91.2 against 72.1 and 84.7, the paper's metric), slightly behind it at two (63.0 against 65.9).
  • On a real machine: the evidence for 114 of 227 questions in the top ten, against 42 to 47 for Spotlight, ripgrep and ripgrep-all, and an agent reads 20 KB to reach it instead of 2.2 to 2.7 MB.
  • Answer accuracy (what memory products usually quote) is a different measure: it scores an answering model and a judge as well as the retrieval. Those numbers are listed below for orientation, in their own tables, never in the same column as ours.

What is measured here is retrieval: did the evidence land on the page an agent reads. Every store was built on the machine by the shipped binaries; no model wrote, rewrote or summarized anything that was indexed.

The benchmark's own strict metric. The official scorer also reports recall_all (EVERY evidence session in the top k) over the 470 questions that have an answer. docenta: lexical 0.832 at five and 0.900 at ten, hybrid 0.843 and 0.917, dense 0.813 and 0.904. The paper's own retriever table (BM25 0.634, Contriever 0.723, Stella 0.720 at five) was measured on the M split, ten times the haystack per question, so it is not a like-for-like row and is not set beside ours. One later paper reports the strict metric on the S split (Associa, ACL Findings 2025): BM25 0.51, Contriever 0.67, Stella 0.70, BGE-m3 0.75, Associa 0.87 at five, with keys built from the user's turns only; read it as orientation, the units are not fully stated.

Where the words differ from the evidence, fusion pays: on preference questions ("what would I like ...") lexical finds 0.73 at five, dense and hybrid 0.93. Where the question quotes the user, lexical wins (0.99 against hybrid's 0.93). The keyword tool is the weak rung by design: it asks for every word, which is right for exact terms and wrong for a question phrased unlike its evidence, and the tool descriptions send questions to the meaning tool for that reason.

LoCoMo: 1,982 questions over ten long conversations

LoCoMo (Maharana et al., ACL 2024, CC BY-NC 4.0), every session one Add and every question one Search, through the same Add/Search adapter docenta entered the Agent Memory Leaderboard with. Conversations hold 19 to 32 sessions, so ten sessions are about a third of a conversation: a generous k, and said so.

The Agent Memory Leaderboard

agentmemoryleaderboard.ai scores memory systems end to end: the system serves Add and Search, the leaderboard fixes the answering model, the prompts and the judge, and reports judged accuracy over a mix of public sets (PersonaMem, LoCoMo-Refined, LongMemEval and others). For orientation, its first cycle (published 2026-08-12, textual track): industry entries from 58.02 (MemoraX) down, Mem0 41.40, MemPalace 39.48; in the academic table a SQLite full-text baseline scored 41.79 and a plain BM25 38.47. docenta entered the second cycle on 2026-10-31 as 0.3.2; its score will stand here when it is published, wherever it lands.

Invented tool calls

A probe in the classes of the Hallucinated-Tools Benchmark (arXiv 2609.19425), whose suite is not published, so this is not an HTB score: 32 invented calls against docenta's MCP surface, 10 honest ones. Every invented tool name is refused and named, no honest call is refused.

The harness

Every number of ours comes from a script in the docenta repository that builds the stores, runs the queries and writes one audit row per question: scripts/eval/longmemeval.py and scripts/eval/lme-official.py (the official metrics), scripts/eval/aml.py locomo, scripts/eval/head-to-head.py, scripts/eval/tool-calls.py. Published numbers are quoted with their source and labelled where the source reports on itself. The repository is in private preview; write to docenta@docenta.ai for the harness and the audit files.
